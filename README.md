# ПЗ.8 Взаимодействие с кодом Kotlin

Проект pz8_Shumejko_PR25-106 по МДК.01.03 «Разработка мобильных приложений»

## Что реализовано

1. Проект создан в Android Studio на Jetpack Compose.
2. Логотип приложения изменён в AndroidManifest.xml (ссылки `android:icon` и
   `android:roundIcon` ведут на новый адаптивный значок с циферблатом в
   `res/mipmap-anydpi-v26/` и `res/drawable/ic_launcher_foreground.xml`).
3. Часы в реальном времени: часы, минуты и секунды по два знака с разделителями;
   обновление каждую секунду.
4. Текущая дата: день, месяц полностью текстом и год из четырёх цифр.
5. Часы и дата размещены на одном экране.
6. Тёмная и светлая темы: свои цвета (primary, secondary, tertiary, background,
   surface) в `ui/theme/Color.kt`, схемы в `Theme.kt` (`lightColorScheme` и
   `darkColorScheme`), нестандартная типографика в `Type.kt` (моноширинный
   шрифт для заголовков).

# Проект назван по шаблону задания: pz8_Shumejko_PR25-106.
- Тёмная тема включается системной настройкой телефона
  (Настройки → Экран → Тёмная тема) - приложение подхватит её автоматически.

## Требования

- Android Studio (Kotlin 2.0, JDK 17)
- Минимальная версия ОС: Android 8.0 (API 26)

## Как запустить

1. Открыть проект в Android Studio.
2. Дождаться синхронизации Gradle.
3. Run ▸ Run 'app'.

## Git

- после проверки создаётся pull request ветки `pz8` в `main` и закрывается.
